# Launch Strategy & Drafts: UHB (Harness Genome)

## Strategy Overview
The launch will focus on emphasizing the critical need for better evaluation frameworks for AI coding agents. The core message is that simple code snippet generation (like HumanEval) is no longer sufficient; we need to benchmark complex, multi-step AI coding workflows. The "Harness Genome" is our solution for standardizing and reproducing these environments.

### Sequence
1. **Twitter / X:** Initial announcement thread to generate buzz and visual interest.
2. **Hacker News (Show HN):** Deep technical dive for developers and founders building AI tools.
3. **r/LocalLLaMA:** Focus on evaluating local models on real-world coding tasks.
4. **r/MachineLearning:** Focus on the methodology, reproducibility, and research implications of the Harness Genome.

## 1. Hacker News (Show HN)
**Title:** Show HN: Harness Genome - Benchmarking AI coding workflows in the wild

**Body:**
Hey HN,

We're open-sourcing UHB today, a framework designed to rigorously benchmark AI coding workflows.

As AI coding assistants and autonomous agents become more capable, evaluating them reliably on complex, multi-step software engineering tasks has become a major bottleneck. Simple function completion benchmarks are no longer enough. We built the **Harness Genome** to address this. It provides a structured, reproducible environment to test AI agents across diverse codebases and realistic scenarios.

Key features:
- **Harness Genome:** A standardized representation of codebase states, task definitions, and evaluation metrics.
- **Reproducible Workflows:** Easily spin up, test, and tear down complex benchmark environments.
- **Agent-Agnostic:** Test any AI coding workflow or agent architecture against a unified standard.

We'd love for you to try it out, break it, and let us know what you think. What benchmarks do you currently rely on for evaluating your AI agents?
